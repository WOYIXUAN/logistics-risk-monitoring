# logistics-risk-monitoring
A logistics analytics project using OCEL event data to investigate shipment delays, build event relationships, and evaluate missed-departure risk.

**业务问题：**哪些物流环节容易造成错过运输班次？能否提前识别风险？
**数据来源：**Container Logistics公开数据，属于仿真物流事件数据。数据集来源：https://zenodo.org/records/18373888
**计划内容：**数据质量检查、对象关系整理、流程等待分析、风险预测、结果展示。
**当前进度：**已下载数据，正在开展数据理解。
**后续更新：**运行方式、实验指标、发现和局限。
